# Optional graded benchmark suite

The graded development suite is available from a
[ContextLean source checkout](https://github.com/andyst-dev/contextlean/blob/main/benchmarks/README.md).
It is not bundled in the small distribution ZIP. Published evidence remains in the
source repository; this package does not alter or replace it.

The installed Benchmark Skill still includes its static estimate helper and its
explicitly requested, read-only Codex A/B workflow. Model measurement is optional
and requires separate authorization. Installation, Bootstrap, updating and
uninstalling do not run benchmarks.
