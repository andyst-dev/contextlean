# Compact-final methodology

The frozen product is commit `90ed9a4a049af519a40c36424ed1ff8b6acefe48`.
The existing repaired harness, task suite, grader, regression tests and acceptance
criteria are byte-identical in the source snapshot. No product code changed.

Bug Fix uses its completed fresh pair from this frozen commit. Its original local
raw data is untouched; public raw copies are byte-identical and referenced by the
combined summary. Eight new ephemeral calls complete Navigation, Feature, Refactor
and Documentation/config, each Vanilla then ContextLean, in the requested order.
Bug Fix had ContextLean first. No previous historical/diagnostic runs are reused.

Each new pair received fresh deterministic guidance generation from the frozen
semantically reviewed compact fixture, not a previous generated AGENTS.md. The
preparing agent reviewed all eight map responsibilities against the source. The
preparation helper checked paths, exact responsibility excerpts, baseline product
equivalence, wrapper and frozen hashes; the transfer verifier checked 71 facets.
Both fixtures and their preparation evidence were checked before each paid call.
Preparation failures stop execution. [Receipts](preparations) retain these checks.
Deterministic checks bind the source review; they do not prove natural-language meaning.

The [local adapter](bug-fix/driver.py.txt) extends product-state comparison to exclude
the root conditional PROJECT_REFERENCE.md, and removes it from Vanilla alongside
AGENTS.md/CLAUDE.md. Startup discovery still counts only AGENTS.md and CLAUDE.md.
ContextLean has 5,478 AGENTS.md bytes, an 11-byte wrapper, and a 2,378-byte optional
reference. The [remaining-call driver](remaining-runs.py.txt) invokes the unchanged
frozen execute_run, usage parser and grade functions. No prompt or metric logic changes.

Both conditions use the same starting product, prompt, model gpt-5.6-terra, low
reasoning, configured provider and temporary workspace path within each pair.
Codex CLI 0.147.0, Darwin arm64, Python 3.14.4 match the Bug Fix and prior clean batch.
Execution uses --json --ephemeral --ignore-user-config --ignore-rules --strict-config,
web_search disabled, approval_policy never, default service tier, no full-access mode.
Navigation is read-only; edit tasks use workspace-write. The plugin itself is absent.
No dependencies are installed. Workspaces omit Git metadata; failed Git checks and
all other diagnostics/recoveries remain in the raw evidence.

Tokens are exact turn.completed.usage fields. Total equals input plus output;
cached input is included in input and reasoning tokens are included in output.
Command calls count unique command_execution event ids. Process wall time uses
the unchanged monotonic execution timer; preparation and grading are excluded.
File reads, unique inspected files, all tool calls and actual credits charged are
unavailable. Dated standard-speed ChatGPT credit-equivalents use the retained rate
card and the existing calculate_credits function, not inferred account usage.

All ten saved solutions were independently offline-regraded after the eight calls:
submitted tests, restored original five regression tests and two independent
acceptance tests per task. Guidance, sample data and read-only integrity are also
checked. Every outcome remains in the summary and all resource regressions appear
in the report. Regrading and quality checks invoke no models.

One run per condition per task is preliminary validation of this tested configuration.
Caching, service load, stochastic outputs and differing order are uncontrolled.
The previous clean-final dataset remains separate. Observed changes establish neither
causality nor statistical confidence; no universal token-savings claim is made.
No further model calls, tag, release or publication upload were performed.

The public bundle retains the original captured JSONL/stderr logs, saved solutions,
run records and grading. Redundant parsed execution summaries remain local because
some contained temporary paths. [Publication review](publication-review.json)
records this exclusion; all measurements and captured logs remain unchanged.
