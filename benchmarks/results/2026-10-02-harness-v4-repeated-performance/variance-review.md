# Observable repetition differences

All thirty tasks passed independent offline grading. These are exposed trajectory differences, not inferred hidden reasoning or exact causal token costs. Detailed evidence is in `commands.md`, `variance.json`, the per-session `execution.json`, and each `solution.diff`.

- **Navigation:** Vanilla used 3/2/2 command calls, including repository-wide discovery and explicit source reads. ContextLean used 1/1/1 calls, searching the mapped source/test directories and executing the sample CLI. Vanilla repetition 1 ran `python3 -m unittest`, discovered zero tests, received exit 5, then recovered with explicit discovery. Vanilla repetition 3 ran the original suite; the ContextLean navigation runs verified ownership and sample execution without running that suite during the measured session. All saved solutions subsequently passed all three offline grading stages.
- **Bug Fix:** All six solutions normalize the incoming category query before filtering. Five reuse the `category` variable; ContextLean repetition 3 uses `normalized_category`. Every solution adds one regression-test method, with two observed method-name variants. Vanilla uses 4/3/6 command calls; ContextLean uses 5/4/5. Exposed merged tool output ranges from 4,866 to 7,266 bytes. The final filter behavior is equivalent under the acceptance tests; trajectories and test assertion contents remain visible in the saved artifacts.
- **Feature:** All six solutions add `select_min_amount`, integrate the decimal threshold into the CLI, update README usage, and add tests. Final submitted suites expose eight test methods except ContextLean repetition 1, which exposes seven. Both repetition-2 sessions run the same eight named tests twice, with an exposed edit to `tests/test_expenses.py` between runs. Equal identity digests establish the test-name list, not identical assertions or complete behavioral coverage. Vanilla uses 5/5/4 command calls; ContextLean uses 4/4/5. ContextLean takes longer in all three pairs despite lower total tokens in two pairs.
- **Refactor:** All six introduce `expense_report/categories.py` and import its shared normalization function into both existing modules. Vanilla keeps the five original test methods. ContextLean repetitions 2 and 3 add `test_filter_query_is_not_normalized` and `test_normalize_category_is_shared_and_compatible`, producing seven methods. Vanilla repetition 1 runs the five-test suite before and after edits. Vanilla repetition 3 receives exit 1 from a compound command ending in an `rg --files` search for absent `AGENTS.md`, then continues successfully. Vanilla uses 5/4/5 command calls; ContextLean uses 5/4/3.
- **Documentation/config:** Every solution changes `config.json` and README to EUR. ContextLean also strengthens the existing `test_configured_default` assertions to require EUR; the test-method list remains five, so that assertion change is visible in the patch rather than a new identity. Vanilla keeps the original tests. Vanilla uses 6/3/7 command calls; ContextLean uses 6/6/7. Vanilla repetition 2 combines verification into fewer calls and has one call containing the recorded verification utilities, compared with three in the other five sessions. Git-containing calls are 2/2/2 for Vanilla and 2/2/3 for ContextLean. Counts are overlapping shell-call categories, not individual command invocations or file opens.

Across the study there are **two nonzero shell-command exits and zero exposed denied commands**. Both nonzero exits above were followed by successful completion; they are not provider or harness failures. There were no provider, quota, preparation, or grading interruptions.

The controlled environment comprises frozen fixture/prompt/source bytes, deterministic Git policy, pinned Python/Git/rg, native permissions, condition policy parity, session-local configuration/cache/scratch roots, and complete root cleanup. All 90 preparation/measured roots are absent and all 30 exposed provider session identifiers are unique. No host-cache diagnostics were observed.

The observed agent trajectory comprises the searches, reads, implementation/test choices, Git checks, failed commands/recovery, verification scope, output sizes, and command counts described above. These vary despite the controlled environment.

Provider caching and service state remain uncontrolled. For example, ContextLean Navigation repetition 2 exposes zero cached input tokens, while its repetitions 1 and 3 each expose 19,584. Feature repetition 3 has fewer ContextLean total tokens but 31,485 uncached input tokens versus Vanilla's 13,057. Thus lower total tokens does not establish lower cost or faster service. No hidden request count, hidden reasoning content, or exact per-action token cost is inferred.
